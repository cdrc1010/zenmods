**Deliverable: One responsive scrolling page with five sections**

| Included work | Amount |
| --- | ---: |
| Branding, page layout, and visual styling using the supplied logo | PHP 1,500 |
| React implementation: Home, Services, Gallery, About, Contact | PHP 1,500 |

| Mobile and tablet layout, keyboard access, and basic browser checks | PHP 750 |
| Deployment setup, source-code handover, and basic page metadata | PHP 500 |

## Included features

- One custom static landing page, with five sections rather than five separate pages.
- Supplied ZenMods logo and matching brand styling.
- Up to three initial carousel photos. Sample images can be replaced with client-provided shop photos.
- Up to three service categories with short descriptions.
- About section and contact information.
- Click-to-call, Facebook inquiry link, and Google Maps directions link once the client supplies verified details.
- Mobile menu, smooth section navigation, and back-to-top link.
- Basic title, description, and semantic page structure. No search-ranking guarantee.
- Two consolidated rounds of minor revisions to text, supplied images, colors, and spacing before final approval.
- Source files and instructions for running and building the website.
- Seven calendar days of bug fixes after handover for defects in the agreed scope.

## Client to provide

Final logo, approved shop photos, confirmed service list, business description, address, opening hours, phone number, official Facebook link, and map link. The current build contains clearly labeled sample photos and proposed service copy. No customer claims, ratings, or testimonials are invented.

## Separate costs and additional scope

Domain registration, hosting subscriptions, renewals, paid assets, and third-party services are excluded from the PHP 5,000 development fee and require a separate agreed budget. Initial deployment configuration is included. No recurring maintenance fee is implied by this quotation.

Online payments, shopping cart, product inventory, customer accounts, admin dashboard, content management, booking system, email delivery, database, and backend are outside this static package. Additional pages, new sections, integrations, ongoing content updates, and revisions beyond the included rounds require a separate quotation.
